About Me

I'm interested in cybersecurity, mainly web application security, network security, and penetration testing. Over the years, I've spent a lot of time learning how systems work, how vulnerabilities appear, and how attackers can exploit weaknesses in applications and networks. I also spend time looking at security from the defensive side — because finding a vulnerability is only one part of the job, and understanding how to prevent it matters just as much.

My main focus is Web Offensive Security and Network Security, but I also have experience with basic OSINT research, Linux security, network traffic analysis, and vulnerability assessment.

I prefer practical work over just learning theory. Most of my learning has involved testing, researching, building lab environments, and documenting technical findings.

My Approach to Security

I believe good security work requires more than simply running tools and collecting vulnerability reports. I try to understand why a vulnerability exists, how it can affect the system, what the actual risk is, and how it can be fixed.

I also prefer working within clearly defined and authorized testing scopes, and keeping technical documentation for my findings.
